# Irregular Verbs! — juego para aprender los verbos irregulares en inglés

Página web estática (HTML + audios). Funciona en móvil, tablet y ordenador.

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `verbos-ingles`) y sube **todos** los archivos de esta carpeta.
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. A los 1-2 minutos estará en `https://<tu-usuario>.github.io/verbos-ingles/`.

## Archivos
- `index.html` — el juego.
- `audio_ava.json`, `audio_sonia.json` — voces en inglés (Ava americana, Sonia británica).
- `audio_es.json` — significados en español.
- `audio_gb.json`, `audio_us.json` — voces infantiles (reserva).

## Compatibilidad
- Micrófono: Chrome y Edge (Windows, Android), Safari (iPhone, iPad, Mac). En Firefox no hay reconocimiento de voz: se corrigen a mano.
- En iPhone/iPad, el reconocimiento usa el dictado de Apple: tiene que estar activado en *Ajustes → General → Teclado → Activar dictado*.
- El progreso se guarda en cada dispositivo (no hace falta cuenta).
