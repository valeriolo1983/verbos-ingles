# What time is it? — juego para aprender la hora en inglés británico

Página web estática (HTML + audios). Funciona en móvil, tablet y ordenador, sin cuenta.

## Publicar en GitHub Pages
1. Crea un repositorio público (por ejemplo `reloj-ingles`) y sube **todos** los archivos de esta carpeta (también `.nojekyll`).
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. A los 1-2 minutos estará en `https://valeriolo1983.github.io/verbos-ingles/reloj/`.

## Archivos
- `index.html` — el juego.
- `audio_en.json` — todas las frases en inglés (voz británica grabada).
- `audio_es.json` — las frases y explicaciones en español.

## Compatibilidad
- Micrófono: Chrome y Edge (Windows, Android), Safari (iPhone, iPad, Mac). En Firefox no hay reconocimiento de voz: se usa el 🎤 del teclado o se escribe.
- En iPhone/iPad hay que tener activado *Ajustes → General → Teclado → Activar dictado*.
- El progreso se guarda en cada dispositivo (no hace falta cuenta).
